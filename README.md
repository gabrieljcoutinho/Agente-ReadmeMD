### Formatação de Texto
- *Itálico* ----> *PALAVRA*
- _Itálico_ -----> _Palavra_
- **Negrito** ---> **PALAVRA**
- NEGRITO --> __PALAVRA__
- ~~Riscar~~ --> ~~PALaVRA~~

### Títulos
- # TITULO nivel 1 (um hashtag)
- ## TITULO nivel 2 (dois hashtags)
